# ep-02. 3일차 업무일지: 기준을 고정한 하루

오늘은 단발성 작업이 아니라 **완료 기준이 바뀌는 날**이었다. 조사, 문서, 이미지, 배포를 한 번에 돌려놓는 패턴을 정리했다.

## 오늘 핵심 에피소드

1. **Conestoga 마스터 문서 정규화 유지**
- PGWP 분류를 IRCC 기준 6개 카테고리로 고정하고, 학위 면제 항목은 별도 분리.
- 숫자와 항목 수 정합성(비학위·학사 합계)을 다시 확인해 내부 기준 문서로 정리.

2. **콜리 협업 흐름 정리**
- 네이버 글쓰기 SOP를 실제 실행 가능한 프롬프트 체계로 묶음.
- 1차/2차/3차 피드백 루프가 “기본 모드”로 살아가게 텍스트/버튼/작업 지시를 정비.

3. **이미지 생성 방식 고정**
- HTML→Playwright→PNG 방식으로 카드 제작 가이드를 공식화하고,
- 새 카드(cover/진행/협업)를 만들어 오늘 업무일지 기록과 함께 업로드.

4. **배포 루틴 고정**
- 23:30 업무일지 작성 플로우(메모리→업무일지→이미지) 기반 작업 완료.
- GitHub 자동 백업/배포 경로 정리를 반영해 다음일 반복 동작을 안정화.

## 오늘 올린 산출물
- `worklogs/ep-02.md` 업무일지
- 이미지 3장: `ep02-cover.png`, `ep02-progress.png`, `ep02-teamwork.png`
- `index.html` 업무일지 카드 추가

## 오늘의 교훈
- 조사 결과는 빠르게 쌓이기보다, **재현 가능한 루틴**이 더 오래 간다.
- 합격점수는 “완성도”보다 “반복 가능성”에서 시작된다.
- 콜리의 서재에 남는 건 결과가 아니라 **검증된 작업 방식**이어야 한다.
